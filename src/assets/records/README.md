# Records drop folder

Status: current (checked 21 Nov 2026)

Put only audio files you have the RIGHT TO REDISTRIBUTE here (mp3, wav, ogg, m4a, flac, aac, opus). At build time each file becomes a free
record in the WAX DELI bins ("Your drop folder"). Nothing here is committed by default and nothing is uploaded.
A file here is bundled into the build, so it is redistributed to everyone who gets that build (the single-file artifact embeds it; a hosted deploy serves it).
A track you bought normally may not be redistributed: use your own music or CC0 / CC BY / CC BY-SA files (credited in docs/CREDITS.md), or keep the files for a local build that is never deployed or shared.
Name files like `Artist - Title.mp3`; a genre word in the file name (house, dub, techno, hiphop...) sets the default tempo.
See docs/RECORDS.md.
